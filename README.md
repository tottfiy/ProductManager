# Product Manager (Lab 03)

## Менеджер товарів

**Менеджер товарів** — це застосунок для обліку складів і товарів, що належать до цих складів. Кожен склад містить набір товарів, які логічно пов’язані саме з ним.

Для кожного товару зберігаються його основні дані (наприклад, назва, кількість, ціна, категорія), а також обчислювані або похідні дані, що використовуються для відображення в інтерфейсі. Товар не може існувати без прив’язки до складу і не може бути прив’язаний до кількох складів одночасно.

---

## Архітектура та структура проєкту

Проєкт реалізовано відповідно до принципів **багатошарової архітектури**, з використанням патерну **MVVM** та підходу **Dependency Injection / IoC**.

### 1. **ProductManager.StorageModels**

У цьому проєкті розміщені моделі зберігання даних, які описують сутності предметної області.

- `Enums.Location.cs` — перелік можливих розташувань складів
- `Enums.ProductCategory.cs` — перелік категорій товарів
- `WarehouseEntity.cs` — сутність складу
- `ProductEntity.cs` — сутність товару

Цей рівень містить лише моделі даних, які використовуються для зберігання інформації.

---

### 2. **ProductManager.Repositories**

Цей проєкт відповідає за взаємодію зі сховищем даних.

- `IStorageRepository.cs` — інтерфейс репозиторію
- `StorageRepository.cs` — реалізація репозиторію
- `FakeStorage.cs` — штучне сховище даних, яке містить початковий набір складів і товарів

Репозиторій надає доступ до даних і повертає сутності рівня `StorageModels`.  
Доступ до `FakeStorage` відбувається через репозиторій.

---

### 3. **ProductManager.Services**

Цей проєкт відповідає за бізнес-логіку та підготовку даних для UI.

#### DTO-моделі:
- `WarehouseListDto.cs` — модель складу для відображення у списку
- `WarehouseDetailsDto.cs` — модель складу для сторінки деталей
- `ProductListDto.cs` — модель товару для списку
- `ProductDetailsDto.cs` — модель товару для сторінки деталей

#### Сервіси:
- `IStorageService.cs` — інтерфейс сервісу
- `StorageService.cs` — реалізація сервісу
- `DependencyInjection.cs` — реєстрація сервісів у контейнері залежностей

Сервісний рівень отримує дані з репозиторію, обробляє їх і повертає DTO-моделі у вигляді, зручному для UI.

---

### 4. **ProductManager.UIModels**

У цьому проєкті реалізовано графічний застосунок на **WPF** з використанням патерну **MVVM**.

#### Основні складові:
- `MainWindow.xaml` — головне вікно застосунку
- `App.xaml.cs` — точка входу застосунку
- `DependencyInjection.cs` — реєстрація UI-компонентів у контейнері залежностей

#### ViewModels:
- `MainViewModel.cs` — головна ViewModel застосунку
- `HomePageViewModel.cs` — ViewModel сторінки списку складів
- `WarehouseDetailsPageViewModel.cs` — ViewModel сторінки деталей складу
- `ProductDetailsPageViewModel.cs` — ViewModel сторінки деталей товару

#### Views:
- `HomePage.xaml` — сторінка списку складів
- `WarehouseDetailsPage.xaml` — сторінка з деталями складу та списком товарів
- `ProductDetailsPage.xaml` — сторінка з деталями товару

#### Навігація:
- `NavigationStore.cs` — зберігає поточну сторінку
- `NavigationService.cs` — забезпечує перехід між сторінками
- `RelayCommand.cs` — реалізація команд для MVVM

UI-рівень не працює напряму з репозиторіями або сутностями зберігання.  
Уся взаємодія відбувається через **Services** та **DTO-моделі**.

## Функціональність застосунку

Після запуску застосунку користувач може:

- переглянути список усіх складів;
- побачити основну інформацію про кожен склад;
- перейти на сторінку деталей вибраного складу;
- переглянути список товарів, що належать цьому складу;
- перейти на сторінку деталей окремого товару;
- повернутися назад до попередньої сторінки.

Застосунок працює в одному головному вікні, а навігація реалізована через зміну сторінок усередині нього.

---

## Використані підходи

У роботі використано:

- **WPF** для побудови графічного інтерфейсу;
- **MVVM** для розділення UI та логіки;
- **Repository Pattern** для доступу до даних;
- **Service Layer** для обробки даних;
- **DTO Models** для передачі даних у UI;
- **Dependency Injection / IoC** для зв’язування компонентів.
